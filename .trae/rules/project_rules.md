# 项目规则

> Trae 平台基础规则，定义核心工作流程和 Skills 调用规范。

## 🎯 核心原则

### 项目启动：梳理可用技能

在项目开始时，SOLO Coder 必须：

1. **检查所有可用 Skills**
   ```bash
   ls .trae/skills/
   ```

2. **了解核心 Skills 的功能**
   - 阅读 `se-lifecycle/SKILL.md` - 了解工作流程
   - 阅读各阶段 Skill 的 `SKILL.md` - 了解具体能力

3. **为项目制定 Skills 使用计划**
   - 根据工作流程，提前规划每个阶段需要调用的 Skill
   - 记录在项目上下文中，作为执行指南

---

4. **初始化项目上下文**
   - 运行初始化命令：`python .trae/skills/se-context/scripts/init_context.py "项目名称"`
   - 自动创建 `docs/context/project_state.json` - 项目状态文件
   - 模型将在需求分析后自动生成 `.trae/rules/skills_rules.md` - 项目专用的 Skills 使用规则

**重要**：每个阶段完成后，必须调用 `se-context` 更新项目状态！

---

## 📋 工作流程

所有项目统一采用完整流程，由 subagent 自动判断、修改和推进：

```
需求分析 → 用例图 → 自动确认
架构设计 → 架构图+ER 图 → 自动确认
详细设计 → 类图 + 流程图 → 自动确认
迭代开发 → 垂直切片 → 自动验收
测试验证 → 测试报告 → 完成
```

**关键原则**：

- ✅ subagent 自动判断输出质量
- ✅ 自动修改完善，无需人工干预
- ✅ 自动确认后进入下一阶段
- ✅ SOLO Coder 负责协调和状态管理

## 🤖 Agent 模式

| 模式                   | 使用场景               |
| ---------------------- | ---------------------- |
| **agent** (默认) | 单一任务，快速实现     |
| **plan**         | 多步骤，需要规划       |
| **spec**         | 复杂需求，需要详细设计 |

| 规则类型 | 文件                          | 说明                 |
| -------- | ----------------------------- | -------------------- |
