## 架构图模板

```mermaid
graph TB
    title 系统架构图
    
    subgraph 前端层
        Web[Web 应用]
        Mobile[移动应用]
    end
    
    subgraph 网关层
        API[API 网关]
        Auth[认证服务]
    end
    
    subgraph 业务层
        User[用户服务]
        Order[订单服务]
        Product[产品服务]
    end
    
    subgraph 数据层
        DB[(数据库)]
        Cache[(缓存)]
        Search[搜索引擎]
    end
    
    Web --> API
    Mobile --> API
    API --> Auth
    API --> User
    API --> Order
    API --> Product
    User --> DB
    Order --> DB
    Product --> DB
    User --> Cache
```

## 使用指南

1. **复制模板** 到项目根目录
2. **填写技术选型** 使用评估模板
3. **绘制架构图** 使用 se-diagram
4. **记录决策** 使用 DEC-xxx 格式
