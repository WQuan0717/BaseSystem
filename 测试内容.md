## 📋 项目需求梳理

### 核心定位
**ForgeMind** 是一个面向铸造行业的桌面客户端平台，通过自然语言交互实现几何生成、铸造仿真和AI分析的全流程自动化。

### 技术栈
| 层级 | 技术选型 |
|------|---------|
| 桌面框架 | Electron（Web技术栈构建桌面应用） |
| 后端 | Python FastAPI |
| LLM | LongCat-Flash-Chat（优先），支持自定义模型 |
| 几何引擎 | CadQuery（真实求解器） |
| 仿真引擎 | OpenFOAM（WSL2本地部署） |
| 界面风格 | 深色专业风 |

### 第一期功能范围
1. ✅ **AI对话机器人** - 连续对话，对话管理，多轮上下文记忆（会话级+用户级）
2. ✅ **几何生成** - 简单模板（冒口、浇口、直浇道等铸造单元）+ 自然语言参数修改
3. ✅ **几何导出** - 支持STL/STEP等多种工业格式
4. ✅ **铸造仿真** - 热传导仿真（凝固过程温度场预测）
5. ✅ **AI仿真结果分析** - 温度场分布、凝固时间、缺陷预测（缩孔/缩松）等所有维度
6. ✅ **几何优化** - AI根据工艺标准自动优化几何设计和铸造参数
7. ✅ **报告导出** - PDF报告、Excel/CSV数据、仿真图片

### 暂不包含（后续迭代）
- 多智能体协同系统
- 多模态RAG知识库
- 复杂的流动仿真
