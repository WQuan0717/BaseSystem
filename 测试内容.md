### 🔧 核心技术栈

| 组件 | 技术 |
|------|------|
| 桌面框架 | Tauri 2.x |
| 前端 | React 18 + TypeScript + Zustand |
| 后端 | Rust |
| 几何引擎 | CadQuery 3.1.0 (Docker) |
| CAE 求解器 | OpenFOAM icoFoam (Docker) |
| 数据库 | PostgreSQL + pgVector (Docker) |
| LLM | LongCat-Flash-Chat (云端) |

### 🎯 已实现功能

1. **三栏 UI 布局** - 对话/Agent状态/几何预览
2. **多模型切换** - LongCat/NVIDIA 托管模型
3. **意图分析 Agent** - 识别 geometry/simulation/chat 意图
4. **CadQuery 集成** - Docker 容器执行几何脚本
5. **OpenFOAM 集成** - icoFoam 仿真配置与执行
6. **Docker 编排** - postgres/cadquery/openfoam 服务
